# Maryland labor market hypothesis tests

**Dataset:** 152 months of Maryland labor data, 2007–2019 (`Employment__Unemployment__and_Labor_Force_Data.csv`)

**Methods:** One-sample t-test and proportion test

## Key findings

- Average employment was 64.09%, significantly below the assumed 65% benchmark (t = −10.218, p < 0.0001)
- High unemployment (above 6%) occurred in about 40% of months, well above the assumed 25% (p < 0.0001)
