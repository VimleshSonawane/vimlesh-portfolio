# Airline delays exploratory analysis

**Dataset:** 94,636 US flight records (21 fields), Bureau of Transportation Statistics

**Methods:** Exploratory data analysis and visualization

## Key findings

- Late-arriving aircraft was the single largest cause of delay, at 300,000+ delay-minutes
- Delays follow a clear seasonal pattern, peaking in summer and around holidays
