# Washington, D.C. crime incidents, 2024

**Dataset:** 29,288 crime incidents, Metropolitan Police Department (`Crime_Incidents_in_2024.csv`)

**Methods:** Descriptive statistics, time-of-day analysis, and geographic mapping by latitude and longitude

## Key findings

- Thefts cluster during working hours, while assaults and robberies peak in the evening
- Crimes concentrate into visible geographic hotspots

## Files

- [`dc_crime_analysis.R`](dc_crime_analysis.R)
- [`report.docx`](report.docx)

## Run it

Packages: `tidyverse`, `janitor`, `psych`, `lubridate`

Place the dataset file in this folder (the script reads it by file name), then run the script in R or RStudio.
