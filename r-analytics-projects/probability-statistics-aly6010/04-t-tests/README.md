# Two-sample and paired t-tests

**Dataset:** `cats` dataset from the MASS package, plus a sleep-quality dataset

**Methods:** Welch two-sample t-test and paired t-test

## Key findings

- Male cats were significantly heavier than female cats (2.90 kg vs. 2.36 kg, p = 0.0008)
- Meditation significantly improved sleep quality (+0.98 points, p = 0.0199)

## Files

- [`t_tests.R`](t_tests.R)
- [`report.docx`](report.docx)

## Run it

Packages: `MASS`, `ggplot2`

Place the dataset file in this folder (the script reads it by file name), then run the script in R or RStudio.
