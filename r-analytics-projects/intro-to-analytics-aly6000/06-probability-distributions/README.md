# Binomial, Poisson, and normal distributions

**Dataset:** Simulated scenarios plus the `palmerpenguins` dataset

**Methods:** Binomial, Poisson, and normal modeling; simulation; Central Limit Theorem

## Key findings

- Modeled a baseball team's win probability, call-center staffing, and light-bulb defect rates
- Confirmed the Central Limit Theorem empirically using penguin measurements

## Files

- [`probability_distributions.R`](probability_distributions.R)
- [`report.pdf`](report.pdf)

## Run it

Packages: `dplyr`, `ggplot2`, `tidyr`, `janitor`, `palmerpenguins`, `knitr`

Place the dataset file in this folder (the script reads it by file name), then run the script in R or RStudio.
