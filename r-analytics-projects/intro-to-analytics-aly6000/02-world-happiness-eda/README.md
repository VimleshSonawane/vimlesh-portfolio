# World Happiness exploratory analysis

**Dataset:** 2015 World Happiness Report (`2015.csv`), plus a baseball dataset (`baseball.csv`)

**Methods:** Data cleaning with janitor, grouped summaries with dplyr, visualization with ggplot2

## Key findings

- Freedom score and happiness score move together, with a clear positive relationship
- Switzerland, Iceland, and Denmark led on both measures

## Files

- [`world_happiness_eda.R`](world_happiness_eda.R)
- [`report.pdf`](report.pdf)

## Run it

Packages: `dplyr`, `ggplot2`, `janitor`, `knitr`

Place the dataset file in this folder (the script reads it by file name), then run the script in R or RStudio.
