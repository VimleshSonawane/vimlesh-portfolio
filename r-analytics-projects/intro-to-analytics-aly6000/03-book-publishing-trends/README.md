# Book publishing trends, 1990–2020

**Dataset:** Book records (`books.csv`)

**Methods:** Date parsing with lubridate, cleaning, trend analysis, and visualization

## Key findings

- A handful of publishers (Random House, HarperCollins, Macmillan) dominate the market, despite nearly 2,000 active publishers

## Files

- [`book_publishing_trends.R`](book_publishing_trends.R)
- [`report.pdf`](report.pdf)

## Run it

Packages: `janitor`, `lubridate`, `dplyr`, `ggplot2`, `knitr`

Place the dataset file in this folder (the script reads it by file name), then run the script in R or RStudio.
