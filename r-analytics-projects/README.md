# R analytics projects

Data analysis and statistics projects in R, completed for my graduate coursework at Northeastern University. Each project includes the R script and a written report with methodology and findings.

**Author:** Vimlesh Sonawane · [Portfolio](https://vimleshsonawane.com) · [LinkedIn](https://www.linkedin.com/in/vimlesh25)

## Highlights

| Project | What it found |
|---|---|
| [Social media addiction, mental health, and sleep](probability-statistics-aly6010/07-social-media-addiction-final/) | In a survey of 705 students, addiction explained 89% of the variance in mental health scores and 58% in sleep hours |
| [NYC motor vehicle collisions](probability-statistics-aly6010/05-nyc-crash-regression/) | Across 100,000 crashes, vehicle count and crash hour were the significant predictors of injuries |
| [Maryland labor market](probability-statistics-aly6010/03-maryland-employment-hypothesis-tests/) | Over 152 months, employment ran significantly below the assumed 65% benchmark |
| [NYC restaurant inspections](probability-statistics-aly6010/06-nyc-restaurant-inspections-regression/) | Violation severity, not borough, was the consistent driver of inspection scores |
| [D.C. crime incidents](probability-statistics-aly6010/02-dc-crime-analysis/) | Across 29,288 incidents, thefts peak during work hours while assaults and robberies peak in the evening |
| [Airline delays](probability-statistics-aly6010/01-airline-delays-eda/) | Late-arriving aircraft was the largest cause of delay across 94,636 flights |

## Skills and tools

- **Statistics:** hypothesis testing (one-sample, Welch, and paired t-tests, proportion tests), correlation, simple and multiple regression, dummy-variable regression, probability distributions, Central Limit Theorem
- **Data work:** cleaning, reshaping, date handling, exploratory analysis, geographic plotting
- **R packages:** tidyverse (dplyr, ggplot2, tidyr, readr, lubridate, stringr), janitor, psych, stargazer, plotly, MASS, palmerpenguins

## Running the code

Datasets are not included in this repository because of their size. Each project's README names the dataset and its public source. Download the file, place it in that project's folder, and run the script in R or RStudio.
